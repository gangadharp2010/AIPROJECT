# Ad Targeting Optimization

## Project overview

This project studies data-driven advertisement targeting using the ad-click dataset stored in this folder. The approach material describes a combination of unsupervised machine-learning and deep-learning ideas for analyzing audiences and supporting targeting decisions.

## Objectives

- Understand the advertising dataset, feature types, and data quality.
- Explore user, campaign, and interaction patterns.
- Prepare relevant inputs for segmentation and targeting analysis.
- Investigate unsupervised learning approaches for identifying audience groups.
- Explore deep-learning-based targeting or optimization approaches as described in the project notebook.
- Interpret results in the context of audience relevance and campaign decisions.

## Repository artifacts

- `ad_click_dataset.csv` — dataset used by the project.
- `Ad_Targeting_Optimization_FIXED_FINAL.ipynb` — main notebook.
- `Ad Targeting Optimization_ Approach Document (Unsupervised ML + Deep Learning).pdf` — approach material.
- `Ad Targeting Systems_ Dataset Overview.pdf` — dataset documentation.
- `Targeting_Optimization_final_submitted.pdf` — final project report.

## Run the notebook

1. Open the notebook in Google Colab or Jupyter.
2. Make `ad_click_dataset.csv` available in the runtime.
3. Verify the dataset path and required dependencies.
4. Execute the cells in order.
5. Review the notebook's segmentation, experiments, and evaluation outputs.

## Technology

The repository materials indicate Python, Jupyter/Google Colab, unsupervised machine learning, and deep-learning experimentation. Refer to the notebook for the exact libraries and versions used.

## Evaluation and limitations

Use the notebook's reported evaluation outputs when comparing approaches. Do not infer campaign lift or causal improvement from segmentation or predictive scores alone. Validate audience groups with campaign experiments and monitor targeting quality, reach, fairness, and business outcomes before operational use.

## Project status

The repository contains a dataset, notebook, approach document, and final report. Re-run the notebook in a clean environment before treating any reported output as reproducible.
