# Project TuneCraft — Efficient LLM Customization with LoRA

## Project overview

Project TuneCraft demonstrates parameter-efficient fine-tuning of a pretrained instruction-following language model. Instead of updating every model parameter, Low-Rank Adaptation (LoRA) adds trainable adapter weights to selected model layers.

The notebook is designed around TinyLlama-1.1B-Chat-v1.0 and the Databricks Dolly-15K instruction dataset.

## Objectives

- Evaluate the base model before fine-tuning.
- Prepare instruction/response examples in a conversational format.
- Configure LoRA adapters for selected model modules.
- Run supervised fine-tuning with the Hugging Face ecosystem.
- Save the trained adapter separately from the base model.
- Compare base-model and adapter-enabled responses.

## Fine-tuning workflow

```text

        v

        |

        |
        v

```

## Run the notebook

1. Open the notebook in Google Colab.
2. Select a GPU runtime (the notebook was designed for a Colab T4-class GPU).
3. Review the package-installation cell and use versions compatible with the selected PyTorch/CUDA runtime.
4. Run the notebook cells sequentially.
5. Review the base-model and fine-tuned outputs.
6. Download or inspect the adapter artifact generated by the notebook.

Large-model and GPU dependencies can change over time. Pin a tested set of `torch`, `transformers`, `trl`, `peft`, `datasets`, and `accelerate` versions for reproducible runs rather than automatically upgrading every package in an existing runtime.

## Evaluation notes and limitations

Adapter training demonstrates a technical workflow; it does not by itself prove improved response quality. Compare base and fine-tuned models using a consistent held-out evaluation set, documented prompts, task-specific scoring, and human review. Monitor for overfitting, memorization, unsafe outputs, and regressions on general tasks.

The adapter requires a compatible base model and tokenizer. It is not a standalone full language model.
