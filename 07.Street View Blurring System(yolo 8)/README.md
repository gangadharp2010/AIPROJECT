# Street View License Plate Detection & Blurring — YOLOv8

## Project overview

This computer-vision project explores automated license-plate detection and image anonymization. The intended workflow detects plate regions in street-view or vehicle imagery and applies blurring so that registration details are obscured in the resulting image.

## Objectives

- Inspect and prepare the image dataset for object detection.
- Configure and use a YOLOv8 detection workflow for license-plate localization.
- Train or evaluate the detector using the dataset and notebook workflow.
- Extract predicted bounding boxes and map them to image regions.
- Blur detected plate regions while preserving the rest of the image.
- Review detection and blurring outputs for missed plates and false detections.

## Run the notebook

1. Clone or download this repository.
2. Open `finalyolov8licenceplatedetection.ipynb` in Google Colab or Jupyter.
3. Download or mount the dataset and configure the dataset paths expected by the notebook.
4. Install the dependencies required by the notebook.
5. Execute the cells in order and inspect both detection and blurred-image outputs.

## Evaluation and limitations

Review detection quality using the dataset's available annotations and the evaluation outputs generated by the notebook. Inspect missed plates, false detections, bounding-box alignment, and blur coverage. Do not assume a plate is anonymized merely because the detector ran successfully.

This is a learning and demonstration project, not a certified privacy-protection system. False negatives can expose identifying information. Any operational use should include human review, conservative fallback behavior, representative testing across lighting/camera conditions, and privacy/security validation.
